# 🌱 Real Life Student Balancer

A professional-grade productivity portal and wellness support system. This application evaluates a student's unmovable life constraints alongside their active academic course load to dynamically analyze workload stability, prevent operational burnout, and protect student well-being.

## 🚀 Core Systems Architecture
*   **Time-Resource Optimization Engine:** Tracks weekly fixed employment and family commitment hours against estimated credit unit study loops.
*   **Instant Well-Being Pulse Triggers:** A live-updating data interface checking subjective exhaustion, stress, and coursework pressure values to offer direct mental health resources.
*   **Academic Roadmap Tracker:** A pre-loaded course roadmap map pulling program metrics directly from the Valencia College Associate in Science Computer Programming and Analysis curriculum track.
*   **Community Support Hub:** Bridges the gap between academic pressure and real-world care with direct resources for crisis intervention (211), food pantries, and basic essentials.

## 🛠️ Tech Stack & Dependencies
*   **Frontend Interface Wrapper:** Streamlit Web Framework Environment
*   **Core Logic Runtime Engine:** Python 3
*   **External Assets API:** Google Fonts Ecosystem (Poppins Typography Grid)
